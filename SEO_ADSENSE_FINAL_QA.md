# Snay3i Final SEO + AdSense QA

## Hard requirements before calling the production build complete
- Homepage, service/city pages and static pages must contain truthful claims.
- No unsupported verification, ratings, reviews, 24/7, guarantee or numeric marketplace claims.
- Empty service/city result pages should not be presented as rich search-result pages to Google.
- Canonicals must match the visible URL.
- Sitemap must contain only intended canonical URLs.
- robots.txt must remain crawlable for public content.
- Privacy, terms, contact and consent infrastructure must remain reachable.
- AdSense publisher configuration and ads.txt must not be removed.
- Analytics must respect the consent configuration.
- Phone/WhatsApp actions must be usable and must not fabricate contact details.
- SEO copy must provide practical information beyond keywords.
- No mass-generated doorway pages.

## Current production constraint
The AdSense application is already submitted. Do not withdraw or resubmit it as part of ordinary SEO/product improvements.
